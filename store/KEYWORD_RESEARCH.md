# English Play Store listing research — 2 October 2026

Recommended title: **Merge Seven: Hexa Puzzle** (24 characters). The existing in-app brand remains Merge Seven. This listing draft is local; nothing was uploaded.

Recommended short description: **Merge hexagon numbers, build satisfying chains and relax with offline puzzles.** (78 characters).

The full description is in `en-US/full-description.txt`. Use the same title and description on the initial English listing; use properly localized copy for additional languages.

## Positioning and keyword selection

| Phrase | Relevance to this app | Placement |
|---|---|---|
| hexa puzzle / hexagon puzzle | Board shape and core genre | Title and first paragraph |
| merge numbers / number puzzle | Actual three-connected-equal-number mechanic | Short description, rules, Daily mode |
| chain reactions | Main moment of satisfaction | Opening paragraph and gameplay copy |
| relaxing puzzle / offline puzzle | Zen and offline normal modes | Opening and offline section |
| daily puzzle / daily challenge | Returning-player feature | Mode list and reminder copy |
| hexagon tile / rotate pieces | Concrete interactions | Rules and visual description |

These are intent and relevance hypotheses from visible listings, not measured search-volume or keyword-difficulty estimates. We do not have Play Console search-term data or a paid keyword dataset.

## Sources and interpretation

- [Merge Hexa Number Puzzle Game](https://play.google.com/store/apps/details?hl=en_US&id=com.inspiredsquare.jupiter1) prominently combines number-puzzle and hexagon-merge positioning. This supports genre relevance, while also showing established competition.
- [Hexa - Merge game](https://play.google.com/store/apps/details?hl=en_CA&id=block.hexa.merge.puzzlegame.number) describes a three-matching-number mechanic. This is a closer search-intent match to our preserved rules.
- [Hexa Sort](https://play.google.com/store/apps/details?hl=en-US&id=com.gamebrain.hexasort) centers on organizing colored tile stacks. Its presentation can inform feel, but advertising this game as that title or as a color-stack sorting game would misrepresent the implemented mechanics.
- [Google: get discovered in search](https://support.google.com/googleplay/android-developer/answer/4448378) explains that discovery depends on multiple factors. Relevant copy alone does not guarantee ranking or a ranking time.
- [Google metadata policy](https://support.google.com/googleplay/android-developer/answer/9898842) prohibits misleading metadata and irrelevant/excessive keywords. Avoid competitor names, keyword stuffing, “#1”, guaranteed rankings or promotional price claims.
- [Google listing setup](https://support.google.com/googleplay/android-developer/answer/9859152) specifies title 30 characters, short description 80 characters, full description 4,000 characters. Draft files are checked locally against these limits.
